# 共催イベントの売上分け（cohost-split）

2〜4人で開いたイベントの売上（誰が受け取ったか）と経費（誰が立て替えたか）を入れると、残りを均等か割合で分けて、「みどり → さくら 3,600円」のように誰が誰にいくら渡すかを出す1ページの道具です。明細はリンクにして一緒に開いた相手に送れます。相手はリンクから同じ明細を見て、違っていれば直して送り返せます。

- 明細の内容はURLの `#` 以降に入ります。サーバー・アカウントは使いません
- **このページはお金を動かしません。振込先や口座は扱いません。** 入力した内容はブラウザの中で計算します（閲覧数の計測に Cloudflare Web Analytics を使っています）
- 税金の扱い（どちらの売上にするか等）は決めません
- 1円未満は切り捨て、余った端数は一覧の1人目（割合で分けるときは、割合が0%の人を飛ばした最初の人）に寄せます
- リンク・メールアドレス・7桁以上の数字（電話番号・口座番号など）・振込先や口座に関わる言葉・向きを変える文字や見えない文字は入れられないようにしています（すべての言い方は防げません）
- 作る側の下書きはお使いの端末のブラウザ（localStorage）に保存します
